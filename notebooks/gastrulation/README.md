# Gastrulation

- [Mouse gastrulation](mouseGastrulation.ipynb): prepare the paired dataset, train COATI and inspect one UMAP flow view.
- [Pretrained full-data models](pretrainedModels.ipynb): load the archived balanced and unbalanced 20k networks and compare predicted snapshots in the original gastrulation UMAP.
- [Held-out distribution reconstruction](heldoutDistribution.ipynb): evaluate strict E8.0/E8.5 LOSO predictions with six RNA/ATAC distribution scores and compare truth with balanced and unbalanced predictions in one global RNA UMAP.
